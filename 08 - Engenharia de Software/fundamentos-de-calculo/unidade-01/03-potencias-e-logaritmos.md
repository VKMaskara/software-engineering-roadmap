# Equações e Inequações

# Equações do Primeiro Grau

## 1. O que é uma equação?

Uma equação é uma igualdade matemática que contém um valor desconhecido chamado de **incógnita**.

Exemplo:

```text
x + 3 = 8
```

A letra `x` representa o número que precisamos descobrir.

Pense assim:

> Qual número, somado a 3, resulta em 8?

```text
x = 5
```

Pois:

```text
5 + 3 = 8
```

Resolver uma equação significa encontrar o valor da incógnita que torna a igualdade verdadeira.

---

## 2. Equação não é apenas uma expressão

Comparando:

```text
2x + 4
```

Aqui temos uma **expressão algébrica**. Não existe uma igualdade e, sem ela, não temos uma equação para resolver.

Agora:

```text
2x + 4 = 10
```

Isso é uma equação, pois possui:

- Uma igualdade;
- Uma incógnita;
- Uma condição que precisa ser satisfeita.

---

## 🧠 Analogia da Balança

Uma equação funciona como uma balança em equilíbrio:

```text
x + 3 = 8
```

O lado esquerdo possui `x + 3`, enquanto o lado direito possui `8`.

Os dois lados têm o mesmo valor.

Para preservar o equilíbrio, qualquer operação realizada de um lado também deve ser realizada do outro.

Subtraindo `3` dos dois lados:

```text
x + 3 - 3 = 8 - 3

x = 5
```

Podemos pensar como:

```text
1º membro = 2º membro
```

# Equação do Segundo Grau

## O que caracteriza uma equação quadrática?

Ela é escrita da seguinte forma:

```text
ax² + bx + c = 0
```

Com:

```text
a ≠ 0
```

Os elementos são:

- `x`: incógnita;
- `a`: coeficiente de `x²`;
- `b`: coeficiente de `x`;
- `c`: termo independente.

Ela é uma equação do segundo grau porque o maior expoente da incógnita é `2`.

Exemplo:

```text
2x² - 5x + 3 = 0
```

Temos:

```text
a = 2
b = -5
c = 3
```

### 📌 Ponto de observação

O sinal faz parte do coeficiente.

Portanto, em:

```text
-5x
```

Temos:

```text
b = -5
```

E não:

```text
b = 5
```

---

## Equação Completa e Incompleta

Uma equação é **completa** quando aparecem os três termos:

```text
ax² + bx + c = 0
```

Ou seja, `a`, `b` e `c` são diferentes de zero.

Uma equação é **incompleta** quando `b`, `c` ou ambos são iguais a zero.

Exemplos:

```text
x² - 9 = 0
```

Aqui:

```text
b = 0
```

---

```text
2x² - 8x = 0
```

Aqui:

```text
c = 0
```

---

```text
3x² = 0
```

Aqui:

```text
b = 0
c = 0
```

---

## O que significa resolver?

Resolver uma equação quadrática significa encontrar os valores de `x` que tornam a igualdade verdadeira.

Considere:

```text
x² = 9
```

Existem dois valores possíveis:

```text
3² = 9
```

ou:

```text
(-3)² = 9
```

Portanto:

```text
x = 3
```

ou:

```text
x = -3
```

Uma equação do segundo grau é uma equação em que precisamos encontrar os valores de `x` que satisfazem a igualdade.

# Fórmula de Bhaskara

Para uma equação geral:

```text
ax² + bx + c = 0
```

Podemos utilizar a fórmula:

```text
x = (-b ± √Δ) / 2a
```

Em que:

```text
Δ = b² - 4ac
```

O símbolo `±` significa que fazemos dois cálculos:

```text
x₁ = (-b + √Δ) / 2a
```

e:

```text
x₂ = (-b - √Δ) / 2a
```

---

# Exemplo com Bhaskara

Resolva:

```text
x² - 5x + 6 = 0
```

### 1. Identificar os coeficientes

```text
a = 1
b = -5
c = 6
```

### 2. Calcular o discriminante

```text
Δ = b² - 4ac

Δ = (-5)² - 4 · 1 · 6

Δ = 25 - 24

Δ = 1
```

### 3. Aplicar a fórmula

```text
x = (-b ± √Δ) / 2a
```

Substituindo os valores:

```text
x = (-(-5) ± √1) / (2 · 1)

x = (5 ± 1) / 2
```

Primeira solução:

```text
x₁ = (5 + 1) / 2

x₁ = 6 / 2

x₁ = 3
```

Segunda solução:

```text
x₂ = (5 - 1) / 2

x₂ = 4 / 2

x₂ = 2
```

Portanto:

```text
x₁ = 3
x₂ = 2
```

---

## O Significado do Discriminante

O valor de `Δ` indica quantas soluções reais existem.

| Valor de Δ | Resultado |
| --- | --- |
| `Δ > 0` | Duas soluções reais diferentes |
| `Δ = 0` | Uma solução real, chamada raiz dupla |
| `Δ < 0` | Nenhuma solução real |

---

## 📌 Procedimento Geral

1. Organize a equação na forma:

```text
ax² + bx + c = 0
```

2. Identifique `a`, `b` e `c`, incluindo seus sinais.

3. Calcule:

```text
Δ = b² - 4ac
```

4. Analise o sinal de `Δ`.

5. Aplique a fórmula de Bhaskara:

```text
x = (-b ± √Δ) / 2a
```

6. Verifique as soluções na equação original.


## Inequações de primeiro grau

Uma equação procura valores que tornam os dois membros iguais:

2x+3=9

Uma inequação procura valores que tornam uma desigualdade verdadeira:

2x+3>9

| Símbolo | Leitura          |
| ------- | ---------------- |
| (>)     | maior que        |
| (<)     | menor que        |
| (\geq)  | maior ou igual a |
| (\leq)  | menor ou igual a |

Exemplo

Resolva:

2x+3>9

Subtraindo 3:

2x>6

Dividindo por 2:

x>3

Diferentemente de uma equação, a resposta não é um único valor. São todos os números maiores que 3:

S={x∈R∣x>3}

O número 4 serve, assim como 5, 3,5, 100 etc. O número 3 não serve porque o símbolo é >, e não ≥.

Regra mais importante

Ao multiplicar ou dividir uma inequação por um número negativo, precisamos inverter o sentido da desigualdade.

Exemplo:

−2x>6

Dividindo por −2:

x<−3
	​


O símbolo > tornou-se <.

Por que o sinal inverte?

Sabemos que:

2<5

Multiplicando os dois números por −1:

−2>−5

Na reta numérica, −2 fica à direita de −5, portanto é maior.

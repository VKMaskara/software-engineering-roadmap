# 📌 Resumo da Aula 09

Hoje aprendemos que:

- Existem tarefas que precisam ser executadas várias vezes.
- Estruturas de repetição evitam escrever código repetido.
- Um loop executa um bloco de instruções repetidamente.
- Toda repetição precisa de uma condição de parada.
- Loops infinitos acontecem quando essa condição nunca é atingida.

---

# 📌 Resumo da Aula 10

Hoje aprendemos que:

- `do...while` é uma estrutura de repetição;
- Primeiro executa o bloco;
- Depois verifica a condição;
- Sempre executa pelo menos uma vez;
- A principal diferença para o `while` está na ordem da verificação.

---

# 📌 Resumo da Aula 11

Hoje aprendemos que:

- `for` é uma estrutura de repetição;
- Ele possui:
  - inicialização;
  - condição;
  - atualização;
- É indicado quando sabemos quantas repetições existirão;
- Seu funcionamento é praticamente igual ao do `while`, mudando principalmente a forma de organizar o código.
